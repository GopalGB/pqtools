## Traps, learned the hard way in that session

- **This shell is zsh; the git hooks are bash.** Unquoted `${VAR}`
  word-splits in bash and does not in zsh. A reproduction of the pre-push
  hook returned "0 bytes" and read as a pass. Reproduce hook behaviour under
  `bash -c`, or the check is theatre.
- **Verify with the command that gates, not a cousin of it.** A
  `.gitleaksignore` was committed on the strength of a git-aware gitleaks run;
  the hook scans a `mktemp` diff with `--no-git`, where that fingerprint can
  never match. Replaced by `security/gitleaks.toml`.
- **A review finding is a claim.** One LOW was false — the path it described
  was already typed — and was fixed before being reproduced. Reproduce
  everything, LOWs included; rejecting on evidence is a valid disposition.
- **The estate autocommit bot commits inside this repo on a timer.** It once
  captured a positive-control mutation as HEAD. After any control that
  mutates a tracked file, check `git log -1` before committing.
- `DOCUMENTED_MATCHES` is asserted for **equality**, not as a floor. Raising
  it means running `scripts/sync_builtin_list.py` in the same commit so
  README.md and llms.txt follow.
- Run the suite **sequentially** on this 8 GB machine:
